3. Temuan Forensik & Detail Otentik Produksi

1. Jejak Boilerplate OPD Surakarta

Halaman error 404 pada route /admin dan /auth menampilkan judul "Error 404 - Frest - Bootstrap HTML admin template" dengan path localhost:8080/surakarta/sim-surat-dispertan-surakarta/assets/backend/images/pages/404.png yang mengonfirmasi basis kode bersama antar-OPD Pemkot Surakarta.

2. Pola Obfuscation ID pada URL

Selain integer murni (/profil/detail/7, /berita/detail/398), helper URL di sebagian menu menghasilkan token seperti 6573turnups14658 dan dff3sunshades384473 untuk menyamarkan parameter kunci database.

3. Struktur Penyimpanan Media Hash MD5

Setiap berkas berita, pengumuman, standar pelayanan, dan unduhan disimpan dalam folder /uploads/{modul}/{32_hex_md5}.{ext} guna mencegah tabrakan nama berkas dan serangan path traversal pada saat unggah dokumen.

4. Remediasi Bug HTTP 500 & Iframe

Endpoint /ppid/informasi_setiap_saat dan /ppid/informasi_dikecualikan yang mengalami HTTP 500 di produksi serta blokir X-Frame-Options pada egov.phicos.co.id telah direkonstruksi penuh agar 100% fungsional.
